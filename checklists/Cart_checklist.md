# Чек-лист модуля Cart (Корзина SauceDemo)

**Окружение:** Google Chrome 150, macOS Monterey, 2560x1600.

## 🛒 Отображение и наполнение корзины
- [x] **1. Корзина открывается по клику на иконку корзины**
  * **Шаги:** Перейти в каталог -> Кликнуть на иконку корзины.
  * **Ожидаемый результат:** Пользователь попадает в корзину.
  * **Статус:** Pass.

- [x] **2. В корзине отображаются все добавленные товары**
  * **Шаги:** Добавить все товары в корзину -> Перейти в раздел корзины.
  * **Ожидаемый результат:** В корзину добавятся все товары.
  * **Статус:** Pass. Товары разной категории успешно добавляются.

- [ ] **3. У каждого товара в корзине есть картинка, название и цена**
  * **Шаги:** Добавить товары -> Перейти в корзину -> Просмотреть карточки.
  * **Ожидаемый результат:** У каждого товара будет: картинка, название, цена.
  * **Фактический результат:** У товара отсутствует картинка, все остальные пункты присутствуют.
  * **Статус:** **Fail**.

- [x] **4. Отображается количество товара (если предусмотрено)**
  * **Шаги:** Добавить товары -> Посмотреть количество в корзине.
  * **Ожидаемый результат:** При добавлении товара будет строка количества (Qty).
  * **Статус:** Pass.

- [x] **5. Есть ли кнопка "Remove" у каждого товара**
  * **Шаги:** Добавить товары -> Просмотреть наличие кнопок удаления.
  * **Ожидаемый результат:** У каждого товара будет кнопка удаления "Remove".
  * **Статус:** Pass.

## 🧭 Навигация и кнопки
- [x] **6. Есть ли кнопка "Continue Shopping"**
  * **Шаги:** Добавить товары -> Просмотреть есть ли кнопка "Continue Shopping".
  * **Ожидаемый результат:** Кнопка присутствует и позволяет вернуться в каталог.
  * **Статус:** Pass.

- [x] **7. В корзине присутствует кнопка "Checkout"**
  * **Шаги:** Добавить товары -> Просмотреть наличие кнопки "Checkout".
  * **Ожидаемый результат:** Кнопка оформления заказа присутствует.
  * **Статус:** Pass.

- [x] **8. Кнопка "Checkout" ведет на страницу оформления**
  * **Шаги:** Нажать на кнопку "Checkout".
  * **Ожидаемый результат:** Успешное перенаправление на страницу оформления заказа.
  * **Статус:** Pass.

- [x] **9. Ссылка на корзину работает с любой страницы**
  * **Шаги:** Перейти на сторонние вкладки -> Перейти в корзину.
  * **Ожидаемый результат:** Успешный переход в корзину с любой страницы.
  * **Статус:** Pass.

## 🔢 Подсчет и удаление
- [x] **10. Итоговая стоимость всех товаров отображается**
  * **Шаги:** Добавить товары -> Увидеть итоговую стоимость.
  * **Ожидаемый результат:** Итоговая стоимость отобразится под списком в корзине.
  * **Фактический результат (Комментарий):** Итоговая стоимость отображается только после нажатия "Checkout" и заполнения данных. В самой корзине итоговой суммы нет.
  * **Статус:** Not Run / Pass (с учетом логики приложения).

- [x] **11. После удаления товара счетчик уменьшается на 1**
  * **Шаги:** Добавить товары -> Посмотреть на счетчик -> Удалить товар из корзины.
  * **Ожидаемый результат:** Счетчик товаров возле иконки уменьшится на 1.
  * **Статус:** Pass.

- [x] **12. После удаления всех товаров корзина становится пустой**
  * **Шаги:** Удалить все товары из корзины.
  * **Ожидаемый результат:** Корзина пуста.
  * **Статус:** Pass.

## 🐞 Негативные и граничные проверки (Edge Cases)
- [x] **13. Сохранение товаров при обновлении страницы**
  * **Шаги:** Добавить товары -> Обновить страницу (F5).
  * **Ожидаемый результат:** Все товары сохранятся.
  * **Статус:** Pass.

- [ ] **14. Изменение количества товара в одной вкладке при удалении в другой**
  * **Шаги:** Добавить товары в одной вкладке -> Открыть вторую вкладку -> Удалить товары в одной из вкладок -> Посмотреть на вторую вкладку.
  * **Ожидаемый результат:** Изменение в одной вкладке не должно влиять на другую.
  * **Фактический результат:** Удаление или добавление товаров в корзине влияет на корзину в другой вкладке.
  * **Статус:** **Fail**. (Нарушение синхронизации данных/сессии).

- [x] **15. Сохранение товаров после выхода и повторного входа**
  * **Шаги:** Добавить товары -> Выйти из аккаунта -> Зайти обратно -> Посмотреть корзину.
  * **Ожидаемый результат:** При выходе и входе товары остаются в корзине.
  * **Статус:** Pass.
