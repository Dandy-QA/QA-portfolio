# Чек-лист модуля Catalog (SauceDemo)

**Окружение:** Google Chrome 150, macOS Monterey, 2560x1600.

## 🖼️ Отображение товаров и UI
- [x] **1. Все товары в каталоге отображаются**
  * **Шаги:** Открыть сайт -> Войти (`standard_user`) -> Перейти в каталог.
  * **Ожидаемый результат:** Отображается 6 товаров.
  * **Статус:** Pass. Пользователь увидит 6/6 товаров в каталоге.

- [x] **2. У каждого товара имеется изображение**
  * **Шаги:** Перейти в каталог -> Просмотреть каждую карточку.
  * **Ожидаемый результат:** У 6/6 товаров присутствует корректное изображение.
  * **Статус:** Pass.

- [x] **3. У каждого товара есть цена**
  * **Шаги:** Перейти в каталог -> Просмотреть карточки на наличие цены.
  * **Ожидаемый результат:** У всех товаров присутствует цена со знаком валюты ($).
  * **Статус:** Pass.

- [x] **4. У каждого товара есть кнопка "Add to Cart"**
  * **Шаги:** Перейти в каталог -> Просмотреть карточки на наличие кнопки.
  * **Ожидаемый результат:** У каждого товара будет присутствовать кнопка "Add to Cart".
  * **Статус:** Pass.

- [ ] **5. Изображение товара соответствует названию товара**
  * **Шаги:** Войти под пользователем `problem_user` -> Перейти в каталог -> Просмотреть карточки.
  * **Ожидаемый результат:** Изображение товара и его название соответствуют друг-другу.
  * **Фактический результат:** Изображения товаров не соответствуют названиям. Все изображения на сайте одинаковые.
  * **Статус:** **Fail**.

## 🔄 Сортировка
- [x] **6. Сортировка Name (A to Z)**
  * **Шаги:** Перейти в каталог -> Выбрать сортировку Name (A to Z).
  * **Ожидаемый результат:** Товары отсортированы по имени от A to Z.
  * **Статус:** Pass.

- [x] **7. Сортировка Name (Z to A)**
  * **Шаги:** Перейти в каталог -> Выбрать сортировку Name (Z to A).
  * **Ожидаемый результат:** Товары отсортированы по имени от Z to A.
  * **Статус:** Pass.

- [x] **8. Сортировка по цене: Price (low to high)**
  * **Шаги:** Перейти в каталог -> Выбрать Price (low to high).
  * **Ожидаемый результат:** Товары отсортированы по возрастанию цены.
  * **Статус:** Pass.

- [x] **9. Сортировка по цене: Price (high to low)**
  * **Шаги:** Перейти в каталог -> Выбрать Price (high to low).
  * **Ожидаемый результат:** Товары отсортированы по убыванию цены.
  * **Статус:** Pass.

## 🛒 Работа с корзиной из каталога
- [ ] **10. Кнопка "Add to Cart" добавляет товар в корзину**
  * **Шаги:** Войти под `problem_user`, `error_user` -> Добавить товары в корзину.
  * **Ожидаемый результат:** Товары успешно добавляются в корзину.
  * **Фактический результат:** Товары либо не добавляются в корзину, либо добавляются с очень долгой задержкой.
  * **Статус:** **Fail**.

- [x] **11. Счетчик корзины в углу увеличивается на 1**
  * **Шаги:** Добавить товар в корзину -> Смотреть на счетчик.
  * **Ожидаемый результат:** Счетчик корзины увеличивается на 1.
  * **Статус:** Pass. При добавлении товара счетчик успешно увеличивается.

- [x] **12. Можно добавить один и тот же товар дважды (если разрешено)**
  * **Шаги:** Попытаться добавить один и тот же товар дважды.
  * **Ожидаемый результат:** Если разрешено, то добавить дважды.
  * **Фактический результат:** Система не разрешает добавление одного и того же товара дважды.
  * **Статус:** Blocked. (Ограничение логики самого приложения).

## 🔗 Навигация
- [x] **13. Клик на картинку товара открывает карточку товара**
  * **Шаги:** Кликнуть на картинку товара.
  * **Ожидаемый результат:** Открывается карточка товара с названием, картинкой, описанием.
  * **Статус:** Pass.

- [x] **14. Клик на название товара открывает карточку товара**
  * **Шаги:** Кликнуть на название товара.
  * **Ожидаемый результат:** Открывается карточка товара с названием, картинкой, описанием и кнопкой "Add to Cart".
  * **Статус:** Pass.

- [x] **15. Кнопка "назад" в браузере работает корректно**
  * **Шаги:** Перейти в каталог -> Нажать "назад" в браузере.
  * **Ожидаемый результат:** Кнопка перенаправляет на предыдущее действие.
  * **Статус:** Pass.
