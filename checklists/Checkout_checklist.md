# Чек-лист модуля Checkout (Оформление заказа SauceDemo)

**Окружение:** Google Chrome 150, macOS Monterey, 2560x1600.

## 🧭 Навигация и шаг 1: Ввод данных
- [x] **1. Кнопка "Checkout" в корзине работает и ведет на страницу оформления**
  * **Шаги:** Перейти в корзину -> Нажать "Checkout".
  * **Ожидаемый результат:** Успешный переход на страницу оформления заказа.
  * **Статус:** Pass.

- [x] **2. На странице отображается форма (First Name, Last Name, ZIP/Postal Code)**
  * **Шаги:** Перейти на страницу оформления.
  * **Ожидаемый результат:** Успешное отображение формы.
  * **Статус:** Pass.

- [x] **3. Есть кнопка "Continue" после заполнения данных**
  * **Шаги:** Заполнить поля -> Нажать "Continue".
  * **Ожидаемый результат:** Кнопка присутствует и работает.
  * **Статус:** Pass.

- [x] **4. Есть кнопка "Cancel" отменить и вернуться в корзину**
  * **Шаги:** Находиться на странице оформления -> Нажать "Cancel".
  * **Ожидаемый результат:** Возврат в корзину.
  * **Статус:** Pass.

## 🧾 Шаг 2: Обзор заказа (Overview)
- [x] **5. Отображение списка товаров, которые оформляются (с ценами)**
  * **Шаги:** Заполнить данные -> Нажать "Continue".
  * **Ожидаемый результат:** Пользователь видит весь список товаров, цены и итоговую стоимость.
  * **Статус:** Pass.

- [ ] **6. Отображение итоговой суммы заказа**
  * **Шаги:** Заполнить данные -> Нажать "Continue" -> Посмотреть итоговую сумму.
  * **Ожидаемый результат:** Итоговая цена должна отобразиться снизу списка (с учетом налогов).
  * **Фактический результат (Комментарий):** При входе под `standard_user` сумма отображается корректно. Однако при входе под `problem_user` пользователь не сможет перейти на страницу списка товаров, так как не удается заполнить поле Last Name.
  * **Статус:** **Fail / Blocked (под problem_user)**.

- [ ] **7. После нажатия кнопки "Finish" открывается страница "Thank you for your order!"**
  * **Шаги:** Заполнить данные -> Нажать "Finish".
  * **Ожидаемый результат:** Переход на страницу успешного заказа.
  * **Фактический результат:** 
    * `standard_user`: Успешный переход.
    * `problem_user`: Не может заполнить Last Name (тупик).
    * `performance_glitch_user`: Успешный переход (с долгой загрузкой).
    * `error_user`: Заказ оформляется, но кнопка "Finish" неактивна.
  * **Статус:** **Fail (под error_user)**.

- [x] **8. Корзина очищается после оформления**
  * **Шаги:** Оформить заказ -> Вернуться назад / домой -> Проверить корзину.
  * **Ожидаемый результат:** Корзина пуста.
  * **Статус:** Pass.

- [x] **9. Кнопка "Back to home" возвращает домой**
  * **Шаги:** Находиться на странице "Thank you..." -> Нажать "Back to home".
  * **Ожидаемый результат:** Успешное возвращение в каталог.
  * **Статус:** Pass.

## 🔴 Негативные и граничные проверки (Валидация)
- [x] **10. Все поля остаются пустыми**
  * **Шаги:** Оставить все поля пустыми -> Нажать "Continue".
  * **Ожидаемый результат:** Ошибка, переход блокируется.
  * **Статус:** Pass. Кнопка "Continue" не срабатывает.

- [x] **11. Заполнено только поле "First Name"**
  * **Шаги:** Заполнить только имя -> Нажать "Continue".
  * **Ожидаемый результат:** Ошибка "Last Name is required".
  * **Статус:** Pass.

- [x] **12. Заполнено поле "First Name" и "Last Name", "Postal Code" пустой**
  * **Шаги:** Заполнить имя и фамилию -> Нажать "Continue".
  * **Ожидаемый результат:** Ошибка "Error: Postal Code is required".
  * **Статус:** Pass (для `standard_user`). *Примечание: под `problem_user` не дает заполнить Last Name, поэтому проверить нельзя (Blocked).*

- [x] **13. Все поля заполнены корректно**
  * **Шаги:** Заполнить все поля валидными данными.
  * **Ожидаемый результат:** Успешное завершение процедуры заказа.
  * **Статус:** Pass (для `standard_user`).

- [ ] **14. Сохранение данных на шаге "Checkout" при обновлении страницы**
  * **Шаги:** Заполнить поля -> Обновить страницу (F5).
  * **Ожидаемый результат:** Данные сохраняются.
  * **Фактический результат:** При обновлении страницы данные не сохраняются, поля придется заполнять заново.
  * **Статус:** **Fail**.

- [x] **15. Добавить товар в корзину, нажать "Checkout" и вернуться в каталог**
  * **Шаги:** Нажать "Checkout" -> Вернуться в каталог.
  * **Ожидаемый результат:** Все товары в корзине сохраняются.
  * **Статус:** Pass.

---
*Примечание: Специфичные баги для ролей (например, невозможность ввода Last Name у problem_user) оформлены в отдельные баг-репорты.*
