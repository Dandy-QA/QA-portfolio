# Чек-лист модуля Login (SauceDemo)

**Окружение:** Google Chrome 150, macOS Monterey, 2560x1600.

## 🟢 Позитивные проверки (Happy Path)
- [x] **1. Вход с валидными данными**
  * **Шаги:** 1) Открыть сайт. 2) Ввести Username: `standard_user` и Password: `secret_sauce`. 3) Нажать Login.
  * **Ожидаемый результат:** Успешный вход, переход на главную страницу (Каталог).
  * **Статус:** Pass. Система отработала, пользователь перешел в каталог.

- [x] **2. Вход с использованием другого пользователя**
  * **Шаги:** 1) Ввести Username: `problem_user`, `performance_glitch_user`, `error_user`, `visual_user`. 2) Ввести Password: `secret_sauce`.
  * **Ожидаемый результат:** Успешный переход в каталог, корректное отображение данных для каждой роли.
  * **Статус:** Pass (с нюансами). `problem_user` — искаженные картинки; `performance_glitch_user` — долгая загрузка; `error_user` — ошибки при оплате; `visual_user` — визуальные баги UI.

## 🔴 Негативные проверки (Валидация)
- [x] **3. Вход с пустым логином**
  * **Шаги:** 1) Оставить поле Username пустым. 2) Ввести Password: `secret_sauce`. 3) Нажать Login.
  * **Ожидаемый результат:** Ошибка "Username is required".
  * **Статус:** Pass. 

- [x] **4. Вход с неверным паролем**
  * **Шаги:** 1) Ввести Username: `standard_user`. 2) Ввести Password: `wrong_pass`. 3) Нажать Login.
  * **Ожидаемый результат:** Ошибка "Username and password do not match any user in this service".
  * **Статус:** Pass.

- [x] **5. Вход с пустым паролем**
  * **Шаги:** 1) Оставить поле Password пустым. 2) Ввести Username: `standard_user`. 3) Нажать Login.
  * **Ожидаемый результат:** Ошибка "Password is required".
  * **Статус:** Pass.

- [x] **6. Вход с двумя пустыми полями**
  * **Шаги:** 1) Оставить поля Password и Username пустыми. 2) Нажать Login.
  * **Ожидаемый результат:** Ошибка "Username is required".
  * **Статус:** Pass.

- [x] **7. Вход с неверным логином**
  * **Шаги:** 1) Ввести Username: `standard_use` (с опечаткой). 2) Ввести Password: `secret_sauce`. 3) Нажать Login.
  * **Ожидаемый результат:** Ошибка "Username and password do not match".
  * **Статус:** Pass.

- [x] **8. Вход с пробелами в начале/конце логина**
  * **Шаги:** 1) Ввести Username: ` standard_user `. 2) Ввести Password: `secret_sauce`. 3) Нажать Login.
  * **Ожидаемый результат:** Ошибка (логин с пробелами не существует).
  * **Статус:** Pass.

- [x] **9. Вход с использованием спецсимволов**
  * **Шаги:** 1) Ввести Username: `standard_user@#$%`. 2) Ввести Password: `secret_sauce`. 3) Нажать Login.
  * **Ожидаемый результат:** Ошибка валидации.
  * **Статус:** Pass.

- [x] **10. Ввод очень длинной строки (1000 символов)**
  * **Шаги:** 1) Ввести длинную строку в Username/Password. 2) Нажать Login.
  * **Ожидаемый результат:** Форма не пропускает вход, выдает ошибку.
  * **Статус:** Pass. Ввод разрешен, но вход не выполняется.

- [ ] **11. Ввод SQL-функции (' OR '1'='1) [УЯЗВИМОСТЬ]**
  * **Шаги:** 1) Ввести в поле Username: `' OR '1'='1`. 2) Ввести в поле Password: `' OR '1'='1`. 3) Нажать Login.
  * **Ожидаемый результат:** Форма логина не должна разрешать вход и должна выдавать сообщение о неправильном логине и пароле.
  * **Фактический результат:** Форма не разрешает вход, если SQL-функция введена в Username (ошибка валидации). **ОДНАКО, если ввести SQL-функцию в поле Password, пользователь успешно авторизуется на сайте!** (Обход авторизации).
  * **Статус:** **Fail (Критический баг, требует отдельного баг-репорта).**

- [x] **12. Ввод XSS (<script>alert(1)</script>)**
  * **Шаги:** 1) Ввести функцию XSS в поля. 2) Нажать Login.
  * **Ожидаемый результат:** Ошибка, вход запрещен.
  * **Статус:** Pass.

- [x] **19. Сохраняется ли сессия после перезагрузки страницы**

- [x] **20. Ввод Enter при пустом поле логина**

  * **Ожидаемый результат:** Ошибка "Username is required".
  * **Статус:** Pass.
