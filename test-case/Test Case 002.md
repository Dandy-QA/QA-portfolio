# Test Case 002 (Авторизация с неверным паролем)

**Модуль:** Login

**Приоритет:** High

**Предусловие:** Пользователь находится на странице `www.saucedemo.com`

| Step | Action | Test Data | Expected result |
| :--- | :--- | :--- | :--- |
| 1 | Ввести логин в поле "Username" | `standard_user` | В поле отображается текст |
| 2 | Ввести неверный пароль | `secret_sauc` | Пароль скрыт точками |
| 3 | Нажать кнопку "Login" | — | Переход не осуществляется. Появляется сообщение об ошибке: "Username and password do not match any user in this service" |

**Постусловие:** Пользователь не авторизован в системе.

**Статус:** Pass (Пройден).
