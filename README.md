## 🚀 Мои ключевые проекты

### 1. Коммерческое тестирование веб-сервиса (MeetRec)
*   **Что делал:** Провел комплексное тестирование веб-панели для записи и расшифровки встреч (с элементами ИИ) по 19 разделам инструкции пользователя.
*   **Результат:** Составил чек-лист на **113 проверок**, выявил и задокументировал **38 багов** (включая Blocker и Critical). Подготовил отчет с рекомендациями по UI/UX.
*   👉 [Посмотреть примеры баг-репортов и рекомендаций](./MeetRec-Testing/README.md)

*   **Инструменты:** DevTools, Jira (имитация Записи велись в Notion app), Postman.

*   **Теория тестирования:** Техники тест-дизайна (граничные значения, классы эквивалентности, попарное), SDLC, жизненный цикл бага.
*   **Инструменты:** DevTools (Network, Console, Elements), Postman, Git/GitHub, SQL (SELECT, JOIN), HTML/CSS.
*   **Документация:** Чек-листы, тест-кейсы, баг-репорты (в формате Markdown и Notion).
