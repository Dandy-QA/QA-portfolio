# Основы HTML и CSS

В этой папке собраны мои конспекты, примеры кода и скриншоты, которые я изучал в процессе подготовки к тестированию веб-приложений.

**Почему это важно для QA:**
Понимание структуры DOM (HTML) и стилей (CSS) позволяет мне быстрее находить баги верстки, локализовать проблемы с отображением элементов и точно указывать разработчикам на причину ошибки (например, конфликт классов или неверный тег).
