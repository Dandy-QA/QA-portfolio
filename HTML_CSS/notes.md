# Отчет по работе с DevTools (Chrome)

## 🌐 1. Тестирование скорости соединения (Network Throttling)
Проводил тестирование на скоростном и слабом интернет-соединении (5G/3G) через DevTools Network Throttling для выявления проблем с загрузкой UI и скоростью загрузки.

*   **Скриншот №1 (Высокоскоростной интернет 5G):** Загрузка сайта заняла **647 ms**. Вёрстка сайта прогрузилась полноценно, со всеми изображениями, текстом, логотипами, названиями и карточками. При быстром клике на данные внутри сайта ничего не открывается преждевременно.
*   **Скриншот №2 (Низкая скорость 3G):** Загрузка сайта заняла **1.4 min**. Вёрстка сайта прогрузилась кусками, сверху-вниз. UI сайта съезжает влево при загрузке, потом выравнивается после полноценной прогрузки. При быстром клике на данные внутри сайта можно открыть карточку сотрудника (screenshots/Симуляция интернета.png).

## 💻 4. Взаимодействие с DOM через Console
Взаимодействовал с DOM и LocalStorage через браузерную консоль (Console). Вход выполнен под `Admin`.

Были использованы следующие команды:
*   `document.cookie` — отвечает за куки на сайте. Пришел пустой ответ, значит сайт не хранит «куки» в открытом виде (сайт настроен безопасно).
*   `localStorage.getItem('session-username')` — показывает имя текущего пользователя. Пришел ответ `(null)`, отсутствие имени пользователя.
*   `document.querySelectorAll('button').length` — считает, сколько кнопок на странице. Пришла ошибка: *Невозможно запустить данную команду под <anonymous>*.
*   `document.querySelectorAll('img').length` — считает сколько картинок на странице. Пришел успешный ответ: **3 картинки**.
*   `document.querySelector('h3').innerText` — вытаскивает текст из заголовков. Пришла ошибка: *Невозможно считать название, или текст отсутствует под <anonymous>*.
*   `window.innerWidth` — показывает ширину окна в пикселях. Пришел успешный ответ: ширина окна **705 px**.
*   `console.error` — (Тестовая ошибка). В консоли должна появиться красная строка с текстом. После отправки запроса, получаем ответ `ƒ error() { [native code] }`.

Захожу в запрос, вижу, что ушел POST-запрос со статусом **302 Found**. На вкладке `Payload` видно, что у нас есть токен, а также `Username` и `Password`. При тестировании плохой связи на устройствах прогрузка сайта происходит постепенно, существует факт нажатия кнопок при неполной прогрузке сайта.
