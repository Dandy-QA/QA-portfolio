Проводил тестирование на скоростном и слабом интернет-соединении (5G/3G) через DevTools network Throttling для выявления проблем с загрузкой UI и скоростью загрузки.
 
Скриншот №1 - Проверка загрузки верстки и скорости на высокоскоростном интернете 5G. Загрузка сайта заняла 647 ms. Вёрстка сайта прогрузилась полноценно, со всеми изображениями, текстом, логотипами, названиями и карточками. При быстром клике на данные внутри сайта ничего не открывается преждевременно.

Скриншот №2 - Проверка загрузки верстки и скорости на низкой скорости интернета 3G. Загрузка сайта заняла 1.4 min. Верстка сайта прогрузилась кусками, сверху-вниз. UI сайта (изображениями, текстом, логотипами, названиями и карточками) съезжает влево при загрузке, потом выравнивается после полноценной прогрузке сайта. При быстром клике на данные внутри сайта можно открыть карточку сотрудника (пример).
