# BUG-03: Валидация полей происходит не последовательно

**Модуль:** Login
**Серьёзность:** Trivial
**Приоритет:** Low
**Статус:** Fixed
**Дата:** 17.10.2026

**Окружение:** Google Chrome 150, macOS Monterey, 2560x1600.

**Шаги воспроизведения:**
1. Открыть `https://www.saucedemo.com`
2. Оставить поле Username пустым
3. Оставить поле Password пустым
4. Нажать Login
5. Убедиться, что появилось сообщение об ошибке

**Ожидаемый результат:** 
Сообщение об ошибке появляется. Подсвечивается первое поле Username, пользователю предлагается сначала заполнить его.

**Фактический результат:** 
Сообщение об ошибке появляется, но система не подсвечивает первое незаполненное поле, а сразу выдаёт общую ошибку.
