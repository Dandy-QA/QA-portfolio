# BUG-08: Некорректное отображение верстки

**Модуль:** Catalog
**Серьёзность:** Major
**Приоритет:** High
**Статус:** Open
**Дата:** 17.10.2026

**Окружение:** Google Chrome 150, macOS Monterey, 2560x1600.

**Шаги воспроизведения:**
1. Открыть `https://www.saucedemo.com`
2. Ввести Username: `visual_user`
3. Ввести Password: `secret_sauce`
4. Нажать Login
5. Убедиться, что совершен успешный вход в главное меню (каталог)
6. Просмотреть верстку сайта главной страницы (каталога)

**Ожидаемый результат:** 
Иконки бокового меню, корзины, названия сайта, описания товара, цена и кнопки добавления в корзину будут выровнены по сетке, выглядеть корректно. Текста не должны плавать при приближении, не должно быть никаких водных знаков, точек и так далее.

**Фактический результат:** 
Верстка сайта нарушена. Иконки бокового меню, корзины, названия сайта, описания товара, цена и кнопки добавления в корзину не выровнены по сетке. Текст товаров плывет при приближении.
