# BUG-04: Сообщение об ошибке не исчезает после успешного входа

**Модуль:** Login
**Серьёзность:** Trivial
**Приоритет:** Low
**Статус:** Open
**Дата:** 17.10.2026

**Окружение:** Google Chrome 150, macOS Monterey, 2560x1600.

**Шаги воспроизведения:**
1. Открыть `https://www.saucedemo.com`
2. Ввести Username: `standard_use`
3. Ввести Password: `secret_sauc`
4. Нажать Login
5. Убедиться, что появилось сообщение об ошибке
6. Ввести Username: `standard_user`
7. Ввести Password: `secret_sauce`
8. Нажать Login

**Ожидаемый результат:** 
Сообщение об ошибке появляется при введении некорректных данных, поля подсвечиваются красным цветом или красной рамкой. При введении корректных данных и нажатии кнопки "Login" сообщение об ошибке должно исчезнуть и выполниться вход.

**Фактический результат:** 
Сообщение об ошибке появляется, но при введении корректных данных сообщение об ошибке не уходит, хотя вход выполняется.
