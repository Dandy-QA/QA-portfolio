# BUG-09: Кнопка "Remove" в разделе не удаляет товар

**Модуль:** Cart
**Серьёзность:** Major
**Приоритет:** Medium
**Статус:** Open
**Дата:** 19.10.2026

**Окружение:** Google Chrome 150, macOS Monterey, 2560x1600.

**Шаги воспроизведения:**
1. Открыть `https://www.saucedemo.com`
2. Ввести Username: `performance_glitch_user`
3. Ввести Password: `secret_sauce`
4. Нажать Login
5. Перейти в каталог, добавить все товары в корзину
6. Перейти в корзину, начать удалять товары

**Ожидаемый результат:** 
Перейдя в корзину после добавления большого количества товаров, и начать удалять их, нажимая на кнопку "Remove", то товары будут удаляться по очереди без проблем.

**Фактический результат:** 
При быстром или умеренном удалении товаров, кнопка "Remove" перестает работать. Товары не удаляются.
