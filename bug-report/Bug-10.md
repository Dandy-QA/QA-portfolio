# BUG-10: Счетчик корзины не обновляется сразу после добавления товара

**Модуль:** Cart
**Серьёзность:** Minor
**Приоритет:** Medium
**Статус:** In Progress
**Дата:** 07.10.2026

**Окружение:** Google Chrome 150, macOS Monterey, 2560x1600.

**Шаги воспроизведения:**
1. Открыть `https://www.saucedemo.com`
2. Ввести Username: `problem_user`
3. Ввести Password: `secret_sauce`
4. Нажать Login
5. Убедиться, что совершен успешный вход
6. Добавить товары в корзину
7. Проанализировать, как отображается количество товаров в корзине

**Ожидаемый результат:** 
Товары успешно добавляются в корзину и пользователь может видеть, общее количество товаров в иконке корзины. Счетчик корзины обновляется при добавлении новой единицы товара.

**Фактический результат:** 
При добавлении единицы товара в корзину, счетчик корзины не обновляется. Происходят задержки на странице сайта, и страницы корзины.
