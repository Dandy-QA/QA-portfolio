**Модуль:** Login
**Серьёзность:** Minor
**Приоритет:** High
**Статус:** Open
**Дата:** 17.10.2026

**Окружение:** Google Chrome 150, macOS Monterey, 2560x1600.

**Шаги воспроизведения:**
1. Открыть `https://www.saucedemo.com`
2. Ввести Username: `locked_out_user`
3. Ввести Password: `secret_sauce`
4. Нажать Login
5. Убедиться, что появилось сообщение об ошибке и появилась инструкция для разблокировки аккаунта

**Ожидаемый результат:** 
Сообщение об ошибке появляется. Добавляется пошаговая инструкция для разблокировки аккаунта.

**Фактический результат:** 
Сообщение об ошибке (Epic sadface: Sorry, this user has been locked out.), появляется для пользователя. Войти в аккаунт невозможно, отсутствует пошаговая инструкция для пользователя.
