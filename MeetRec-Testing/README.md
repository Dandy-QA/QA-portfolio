# Коммерческое тестирование веб-сервиса MeetRec

**Статус:** Завершен (Ноябрь 2026).
**Роль:** QA Engineer (Manual).
**Тип:** Веб-сервис для записи и расшифровки встреч (с элементами ИИ).

## 📝 Описание задачи
Клиент предоставил доступ к панели MeetRec и подробную инструкцию пользователя (19 разделов).
**Задача:** Провести тестирование UI/UX, функциональное тестирование и проверку работоспособности сервиса. Предоставить отчет и рекомендации по улучшению.

## 📊 Результаты работы
*   Составлен **чек-лист на 113 проверок**, покрывающий все функции сервиса.
*   Выявлен и задокументирован **41 баг** (включая 1 Blocker, несколько Critical и Major).
*   Подготовлен итоговый отчет с рекомендациями по UI/UX.

## 🐞 Самые значимые найденные баги
1.  **Blocker:** Неработающий аудиоплеер (нет перемотки, не работает пауза).
2.  **Critical:** Потеря данных (невозможность сохранить заметки и фото во время записи из-за ошибки сети).
3.  **Major:** Невозможность выключить запись без предварительной постановки на паузу.
4.  **Major:** Ошибка разделения голосов спикеров (диаризации) в стенограмме.
5.  **Security:** Утечка технических данных сервера (IP-адреса, ключи API) в интерфейс чата.
